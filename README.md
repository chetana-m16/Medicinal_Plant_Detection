# Plant Identification ML Web App

A Flask-based web application for identifying medicinal plants using machine learning.

## Features
- User authentication (register/login)
- Plant image upload and prediction
- Plant information database
- User profile management

## Tech Stack
- **Backend**: Flask, TensorFlow
- **Frontend**: HTML, CSS, JavaScript
- **Database**: SQLite
- **ML**: TensorFlow/Keras for image classification
